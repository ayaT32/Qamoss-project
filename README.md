# قاموس
أداة تجمع بين **باحث مصادر** و**مدقق اقتباسات** للمحتوى الإسلامي، تعتمد على
الاسترجاع الموثق (RAG) بدل الاعتماد على معرفة النموذج اللغوي العامة.

## المبدأ الأساسي

لا تُعرض أي إجابة لا يوجد لها نص مسترجَع فعليًا من قاعدة المصادر. النموذج
اللغوي (عبر Groq) لا يُستدعى إلا لتصنيف طبيعة الفرق بين نصين تم استرجاعهما
فعلًا — لا يُستخدم أبدًا لتوليد إجابة مستقلة.

## التشغيل محليًا

```bash
python -m venv .venv
source .venv/bin/activate          # على Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# افتح .env وضع فيه مفتاح Groq المجاني من https://console.groq.com

python -m app.build_index          # يبني الفهرس من ملفات data/*.json
uvicorn app.main:app --reload      # يشغل الخادم على http://127.0.0.1:8000
```

افتح `http://127.0.0.1:8000` في المتصفح لتجربة الواجهة.

## بنية المشروع

```
app/
  normalize.py     تطبيع النص العربي للمطابقة فقط (لا يُعرض للمستخدم)
  build_index.py   يبني قاعدة المتجهات (Chroma) من data/*.json
  retrieval.py     منطق البحث والتحقق — القاعدة الصارمة لمنع الهلوسة هنا
  llm.py           استدعاء Groq لتصنيف الفروق فقط، وفق نظام تعليمات مقيَّد
  main.py          واجهة FastAPI (/search, /verify, /health)
static/
  index.html       واجهة ويب بسيطة ثنائية اللغة الاتجاه (RTL)
data/
  quran_sample.json    عيّنة من القرآن الكريم (Tanzil) — يجب توسيعها
  hadith_sample.json   عيّنة من الأربعين النووية — **تحتاج مراجعة مختص قبل الاعتماد**
```

## البيانات
ملفات `data/*.json` المرفقة هي **عيّنة صغيرة فقط** لإثبات عمل النظام،
وليست قاعدة بيانات كاملة أو نهائية:

- `quran_sample.json` يحتوي على القران كاملا بتنزيل النص الكامل من
  [tanzil.net](https://tanzil.net/download) (صيغة نصية بسيطة) وتحويله لنفس
  الشكل (`id`, `text`, `source`, `reference`, `url`, `license`).
- `hadith_sample.json` يحتوي على 43 أحاديث من الأربعين النووية وكل
  حقل `verified_by_team` فيها `false` — **يجب أن يراجعها عضو مختص بالفريق
  حرفًا بحرف مقابل مصدر موثوق (مثل sunnah.com) قبل اعتمادها**، لأن دقة
  النص هي جوهر ما تثبته الأداة.
